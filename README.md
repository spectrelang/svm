# svm

This is a version manager for the Spectre toolchain versions.

Build requires v0.0.16.

CLI:

```
usage:
  svm <command> [arguments]

commands:
  install <version|latest>  Install a Spectre version
  switch  <version|latest>  Install if needed and activate a version
  list                      List installed versions
  list-remote               List versions available to install
  current                   Print the active version
  uninstall <version>       Remove an installed version
  help                      Show this help message
```
